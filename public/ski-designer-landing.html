What it does

Everything from shape to shop floor.

One bench for the whole design: draw it, feel how it'll flex, and walk away with files a CNC can actually cut.

01

Shape it by hand

Drag nodes to set width and contact points. Pull bezier handles for the exact tip and tail curve. Symmetric or fully asymmetric.

02

Profile & camber

Set camber, tip rise, and tail rise. The side profile is the rocker line your press mold follows.

03

Flex you can feel

Pick your layup — wood core, glass, metal, carbon — and watch a live flex simulation rate how the ski will ride.

04

Real edge geometry

Full-wrap or contact-to-contact steel edges, with an inset base cut that exports as one continuous drag-knife path.

05

Core & taper

Core outline with sidewall inset, plus a side-profile taper for milling the wood blank to thickness.

06

CAD-ready export

Clean DXF and SVG that open in Aspire, Fusion, and FreeCAD — with a combined view aligned for lofting.

Your first ski · start to file

Seven steps from blank canvas to cut file.

Work top to bottom through the panels. Here's the whole path.

1

Start from a preset

Pick a shape — All-Mtn, Powder, Twin Tip — as a sane starting point, then make it yours.

2

Set your dimensions

Length, tip / waist / tail width, tip and tail length. The plan view updates as you type.

3

Shape the tip & tail

Drag nodes for contact points and width; pull the diamond handles in the zoom panels for the curve.

4

Dial the profile

Camber and rise define the rocker line — the shape your press mold is built to.

5

Choose the layup

Wood core, fiberglass, optional metal and carbon. Each choice changes the flex.

6

Tune the flex

Read the flex rating. Adjust core thickness, width, and materials until it rides right.

7

Export & cut

Set edges, then export Base, Core, Core Side, or the Combined file for CAD and CNC.

→

Then build it

Cut the base and core on a CNC, mill the taper, lay up your materials, and press. You designed it — now ride it.

The files you walk away with

Files a shop can actually use.

Every export is clean, unit-accurate DXF and SVG — no mangled layers, no import errors. The base cut runs as a single continuous path for a drag knife. The combined file stacks every view on one length axis, labeled and dimensioned, ready to loft.

  • BASEOutline + edge offset. One continuous drag-knife path for the P-Tex base.
  • CORECore outline with sidewall inset and contact marks.
  • CORE SIDEThickness taper profile for milling the wood blank.
  • COMBINEDAll views aligned on the length axis, labeled, with a measurements table — built for lofting in CAD.
